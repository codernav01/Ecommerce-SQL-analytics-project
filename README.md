# 🛒 E-Commerce SQL Analytics Project

## 📌 Project Overview
This project is a complete **E-Commerce SQL Analysis** designed to simulate real-world business scenarios. It covers the full lifecycle of an online shopping platform — from customer data and product management to order processing, payments, and customer feedback.

The main objective is to **analyze structured data and generate meaningful business insights using SQL**.

---

##  Database Structure
The project is built using a normalized relational database with the following tables:

- **Customers** – Customer details (name, city, state, signup date)  
- **Products** – Product catalog (name, category, price, stock)  
- **Orders** – Order information (date, status)  
- **Order_Items** – Product-level order details (quantity, price)  
- **Payments** – Payment records (method, amount, date)  
- **Reviews** – Customer ratings and feedback
